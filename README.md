# Shah Knits — Handcrafted Crochet Accessories

Simple responsive storefront (HTML + CSS + JS) that lists products from image filenames in this folder.

## Product image naming

Name your product images like:

- `Beige Claw Clip @155.jpg`

The site reads `Name` and `price` from the filename (everything before/after the `@`).

## Run the website

The easiest way is to open `index.html` in a browser.

If your browser blocks loading local images when opening the file directly, run a tiny local server:

```bash
python3 -m http.server 5173
```

Then open `http://localhost:5173` in your browser.
